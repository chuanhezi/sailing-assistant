# Comprehensive Sailing Assistant

综合航海助手 / Comprehensive Sailing Assistant

An in-game information panel for The Pirate: Caribbean Hunt.

## Features

- Current-area player and AI ship list
- All / Player / AI filters
- Official localized ship and cargo names
- Hull, sails, crew, cannons, speed and anchor status
- Player ship cargo capacity and item weight
- Port warehouse inventory
- Current commodity buy and sell prices
- Chinese and English interface
- Saved language selection and panel position

## Requirements

- The Pirate: Caribbean Hunt
- MelonLoader 0.7.3 Mono x64
- Pirate Framework 1.4.0 or later

## Installation

Install Pirate Framework first, then extract this archive into the game root directory:

```text
Mods/PirateExtensions/SailingAssistant.dll
```

Launch the game through Steam.
Open the assistant using the button on the middle-left side of the screen.
Use the 中文 / English button at the bottom of the panel to change language.
